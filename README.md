# 🇮🇳 Indian Union Budget Analysis (2021–2024)

## 📌 Objective
This project analyzes the Indian Union Budget to identify key government priorities using data analysis and machine learning.

## 📊 Dataset
Union Budget data (2021–2024), including ministry-wise allocations.

## 🔍 Key Analysis
- Top ministries by budget allocation (2023–24)
- Growth trends (2021–2024)
- Identification of priority sectors

## 🧠 Key Insights
- Infrastructure sectors like Road Transport and Railways show highest growth
- Welfare sectors show stable or reduced growth
- Energy and MSME sectors show significant increase

## 🤖 AI Prediction
A linear regression model was used to predict budget allocation for 2024–25.

Predicted allocation (Road Transport):
~ ₹3.44 lakh crore

## ⚠️ Limitations
- Limited data points (3 years)
- Prediction is indicative, not exact

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Scikit-learn)
